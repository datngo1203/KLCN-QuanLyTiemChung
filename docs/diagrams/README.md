# Sơ đồ tham khảo

PNG để xem, SVG để phóng to, PlantUML để sửa. `So_do_Use_Case_he_thong_tiem_chung` là use case hệ thống; hiện bản ảnh cũ ghi Windows + Website, mobile mới được bổ sung và dùng chung chức năng khách hàng. Chưa sửa sơ đồ gốc để giả định giảng viên đã duyệt phạm vi mới.

Mô hình quan hệ chia bốn hình để dễ đọc; FK tới bảng ở hình khác vẫn được giữ trong bảng. `Mo_hinh_quan_he_tiem_chung.puml` là nguồn tổng thể. Lớp thiết kế và lớp phân tích được giữ để đối chiếu; khi đổi schema/API, tạo PR mô tả lý do và cập nhật sơ đồ liên quan.
