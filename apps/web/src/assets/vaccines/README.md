# Ảnh sản phẩm vắc xin

`gardasil-9.jpg` là ảnh của Aveaoz, được thu nhỏ từ [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:HPV_Vaccine_Gardasil_9_box.jpg) theo [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

Để chuẩn bị demo cục bộ, lưu các ảnh Long Châu dưới đây vào thư mục `local/` cạnh file này, đúng tên file, trước khi chạy Web hoặc build lại. Git bỏ qua thư mục `local/`. Bản build mang theo các ảnh có mặt lúc build, vì vậy chỉ dùng bản build chứa ảnh Long Châu cho demo cục bộ tới khi có quyền phân phối.
